# PharKeep project agent rules

For any UI work in this repository, use `SKILL.md` (or `.agents/skills/pharkeep-ui-design-system/SKILL.md` if installed there) and its supporting references. Follow the PharKeep design tokens and quality checklist. Preserve Teable Business application behavior, data access, and existing workflow states. Do not treat exported static HTML as the live app implementation. Ask before changing schedule-code meaning, release workflow, access rules, or data schema.
